# 造纸湿部断纸质控规范

## 业务场景

班组在第 255 分钟提交在制卷次的质控决定。快照是合成的纸机 DCS 抄表、ERP 纸种计划和化验记录，含迟上报、量纲混用、重复计数器冲突、换线拼接及计划重叠。部署后先看质控表，再核对待复查卷次的换线区间与模型分裂路径。容量表示班次最多能领样的实验室席位，默认五个。

## 特征与模型

真空统一为 kPa，速度为米每分钟，浓度为百分数。稳定历史按纸种计算 Welford 方差和仪表下限。拼接断开前序短窗口，分机台、分纸种保存真空下降斜率。CART 使用三维标准化特征和 Gini 降幅，叶节点最少五条，概率采用 Laplace 平滑。树的切点取相邻不同值中点。先验不允许超训练范围读数自动放行。

首个命中处置规则依次为同卷冲突、确认的规格越限、未核验严重读数、模型缺失、高风险，再到继续生产。实验室席位对每台机有独立上限，耗尽时保留待位状态与处置证据。样例卷重由现场转速示意折算，化验对账仍使用独立确认的磅单重量。

## 回放

只统计同时有观察、结单、已确认化验的历史行，训练和复盘分别切开水位。全负样本的加权召回保留空值。曲线展示不同处置阈值下漏判的已确认断纸公斤数。对于真实生产，实际安全限制由现场规程和工艺责任人确认。

## 换线和化验复盘

工作台运行证据包含纸种有效期的分钟对账、双侧 CUSUM 真空趋势、不同化验席位的留样损失、CART 单轴反事实及按纸种的可靠性数据。反事实只回放模型对小幅单轴变化的响应，证据保留原路径、目标范围、叶分组样本和阈值变化。稳定分钟与换线、闲置、冲突分钟相加等于班次长度。化验可靠性逐纸种保存已结卷次与磅单体量，概率分箱包含最高档上端点。
